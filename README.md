# Landing-page-
LearnHub Landing Page  A modern and responsive landing page built using HTML5 and CSS3.   LearnHub is an educational platform concept created for demonstration and learning purposes.
Features

• Modern hero section with attractive design
• Responsive navigation bar with hamburger menu
• Dark mode and light mode theme toggle
• Animated marquee strip for announcements
• Features section with interactive cards
• About section explaining the platform
• Call-to-action section to engage users
• Fully responsive design for mobile and desktop devices

Technologies Used

• HTML5
• CSS3
• Google Fonts
• Font Awesome Icons
